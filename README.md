# DLsim

DLsim 是一个系统级的 LLM 推理仿真工具。输入是用配置文件描述的推理网络（器件、互联、部署映射、软件栈）和 AgentX 多用户 agentic 负载，输出是与 InferenceX 行格式一致的系统指标，用于把一个尚未实现的推理系统与已有公开实测的系统（GB300 NVL72 等）放在同一条曲线上比较，并反过来求出达到某个目标所需的器件、互联和软件条件。

它是粗粒度模型。原则是结果的一阶量正确优先于局部精确。

## 当前状态

仓库目前只有设计文档，没有实现代码。实现语言已定为 C++20。
